Depends on `create-native-rust-linux-terminal` (implemented) and `add-serial-sessions` (serial contract). Parallel agents own disjoint areas with `CARGO_TARGET_DIR=target/agent-<name>`: **build** (`Dockerfile`, `docker/`, `scripts/`, `xtask`, workflows, `packaging/`, `deny.toml`), **winadapter** (`crates/platform-windows`, `crates/platform` doc/method), **cfg** (`store`, `engine`, `ssh`, `ui`, `apps/rustxterm`, Unix-only tests). All builds run in Docker. "Compiles" is never the verification of a runtime behavior: runtime checks name the test that runs on the Windows runner (2.5) or the receipt row (3.2).
