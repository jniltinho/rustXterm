# Screenshots

Renders of rustXterm's own UI with its original icon set and fictional data, generated offscreen by the
`rxt-ui` snapshot tests in light and dark themes. Files are `name_theme.png` (1280×800) and `name_theme@2x.png` (2560×1600); click an image for
full size. Regenerate them as described in [DEVELOPMENT.md](../DEVELOPMENT.md#snapshots-and-screenshots).
